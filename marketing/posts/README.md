## English (Reddit r/WebGames, r/IndieGaming, Hacker News "Show HN", Bluesky)

**Title:** I made a daily browser game about getting one document stamped at a Brazilian notary office

> Every day the bureaucracy is generated from a seed, and it's the same for everyone. Window 3 never tells you everything you need at once. Window 4 goes to lunch. Window 2's copier jams on every fourth copy. Every form has one trap for people who fill it in on autopilot.
>
> 3 to 5 minutes, no sign-up, works on a phone. You paste your result like Wordle.
>
> The interesting bit for programmers: every day is guaranteed to be finishable. A solver plays each seed like a careful first-timer, and property tests check 10,000 days. The whole run is a pure function of seed + inputs, so a bug report is just an input log. Source (MIT): https://github.com/allbdev/notary-office-simulator
